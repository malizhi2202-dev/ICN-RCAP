# ICN and RCAP

Two companion theoretical papers on Intelligent Capability Networks and Recursive Capability Registration and Addressing. Each paper is available in English and Chinese, in Markdown, Word and PDF formats.

Start with the discovery paper for the reference-set model and coverage guarantees. Continue with the coordination paper for the conditions connecting a discovered capability to an authorized action and a supported outcome claim.

## Scope and research status

The papers develop definitions, conditional propositions, proofs, counterexamples, and falsifiable research claims. They distinguish established mathematical tools from proposed contributions and untested hypotheses. Analytical examples are not experimental results. References were checked against official sources or original papers on 28 October 2026; Internet-Drafts are identified as work in progress.

This repository contains only these two bilingual papers and their reading guides. Word files use editable native equations; each PDF is a print rendering of its Markdown source. Implementation examples, deployment material, superseded drafts, and separate supplements have been removed.
